**What building these taught me**

- **Make sites readable for agents, not just people.** llms.txt, clean markdown versions of pages and WebMCP tools let AI agents use a site correctly instead of guessing from HTML.
- **Keep the AI close to the data.** Running models in the browser (ONNX, Transformers.js) means user documents never leave the device. Privacy becomes a design choice, not a policy.
- **Hide the data, not the code.** A public GitHub Pages site can still show private data if it's encrypted at build time and decrypted only in the browser.
- **Automate the boring, gate the risky.** Nightly GitHub Actions update dependencies, but only ship when the build and tests pass. Major upgrades still need a human.
- **Accessibility is a feature you test, not a checklist you sign.** axe and Playwright in CI catch regressions that manual reviews miss.
